> *"A model can't improve unless it knows how wrong it was."*

## The Problem

After the forward pass, GPT has generated probabilities.

Suppose the sentence is `The sky is ____` and the correct answer is `blue`.

But GPT predicts `green`.

The model knows it made a mistake. But — **how big was that mistake?**

Was it a tiny mistake? Or a huge one?

We need a way to measure it.

## Cross Entropy Loss

Cross Entropy doesn't only check whether the answer is right. It also considers **how confident** the model was.

## Mathematics

The full Cross Entropy Loss formula is:

<MathBlock title="Cross Entropy Loss">
  $$L = -\sum_{i=1}^{C} y_i \log(p_i)$$
</MathBlock>

where **L** is the loss, **yᵢ** is the correct label (1 for correct token, 0 for all others), **pᵢ** is the predicted probability, and **C** is the vocabulary size.

For language models, only the correct token contributes. The formula simplifies to:

<MathBlock title="Simplified Cross Entropy">
  $$L = -\log(p_{\text{correct}})$$
</MathBlock>

This means a higher probability on the correct word → lower loss. A lower probability → higher loss.

---

## Why Logarithm?

The logarithm makes confident wrong predictions receive much larger penalties than uncertain ones.

We'll study logarithms in depth later when we dive into optimization.

## Common Misconceptions

**Loss is the error itself.**

No. Loss is a measurement of the error.

**Every wrong prediction gets the same loss.**

No. Cross Entropy depends on confidence.

**Higher probability always means lower loss.**

Only if that probability belongs to the **correct** answer.

**Cross Entropy changes the parameters.**

No. It only measures the mistake. Parameter updates happen later.

## Key Takeaways

- Loss measures how wrong a prediction was.
- Cross Entropy uses probabilities, not just correct or incorrect labels.
- Confident wrong predictions receive larger penalties.
- Lower loss means better predictions.
- Loss itself doesn't improve the model — it only provides feedback.
