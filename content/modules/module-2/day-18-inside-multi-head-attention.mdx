## Quick Recap

> **How does GPT actually run multiple attention heads at the same time?**

## Mathematics

<MathBlock title="Head Dimension Formula">
  $$d_{\text{head}} = \frac{d_{\text{model}}}{h} = \frac{768}{12} = 64$$
</MathBlock>

Each head independently computes scaled dot-product attention on its 64-dim subspace:

<MathBlock title="Per-Head Self-Attention">
  $$\text{head}_i = \text{Attention}(XW_Q^i,\; XW_K^i,\; XW_V^i) \quad \text{output: } (3 \times 64)$$
</MathBlock>

## Engineering Insight

Modern GPUs execute thousands of matrix multiplications in parallel. Multi-Head Attention is specifically designed to exploit this — each head's computation is independent, so all 12 run at the same time on different GPU cores.

---

## Key Takeaways

- Every attention head receives the same input embeddings.
- Each head owns its own WQ, WK, WV matrices.
- The embedding dimension is **divided** across heads, not duplicated.
- Each head performs independent Self-Attention on 64 dims.
- All heads execute in parallel — computation stays manageable.
- 12 × 64 = 768: total feature dimension unchanged.
