The first Linear layer isn't one giant calculation. It contains **3072 neurons** for GPT-2 Small — every neuron receives all 768 input features.

## Opening One Neuron

Every neuron performs one computation — the same neuron from Module 1.

<MathBlock title="One Neuron">
  $$\text{output} = \sum_{i=1}^{768} w_i x_i + b$$
</MathBlock>

where **w** are learned weights, **x** are the 768 input features, and **b** is the bias. One neuron → one output value.

---

## Key Takeaways

- A Linear layer contains thousands of neurons.
- Every neuron receives the complete input vector.
- Each neuron has its own learned weights and bias.
- Different neurons detect different patterns during training.
- Together, thousands of neurons transform the token into a richer representation.
