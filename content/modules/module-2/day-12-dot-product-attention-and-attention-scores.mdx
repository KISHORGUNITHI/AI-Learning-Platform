---

## The Problem

Consider the sentence `I love AI`.

Suppose GPT is processing the token `love`.

Should it pay attention to `I`, or `AI`, or both?

If GPT gave every token equal importance, every sentence would be treated almost the same. Language doesn't work like that.

GPT needs to answer one question for every token:

> **How relevant is every other token to me?**

---

## Intuition

Imagine searching for a book in a library. You don't randomly pick books — you compare **what you're looking for** against **what each book is about**.

## Why Query × Key?

GPT compares Query with Key — not with Value.

<TokenMapping
  title="Why This Comparison?"
  fromLabel="Vector"
  toLabel="Purpose"
  items={[
    { from: "Query", to: "What information am I looking for?" },
    { from: "Key",   to: "What information do I contain?"     },
    { from: "Value", to: "What information can I share? (used later)" },
  ]}
/>

The comparison between Query and Key produces a number called the **Attention Score**.

- Larger score → highly relevant tokens
- Smaller score → weak relationship

## Building the Attention Score Matrix

For the sentence `I  Love  AI`, every Query is compared against every Key.

                  textAnchor="middle" fontSize="13" fontWeight={isMax ? '700' : '400'}

The highest score in each row (shown in blue) means that Query finds that Key most relevant. These are **raw scores — not probabilities yet**.

## Understanding the Tensor Shapes

Suppose the sentence has 3 tokens, each with a 768-dimensional embedding.

<TokenMapping
  title="Dimension Walkthrough"
  fromLabel="Matrix"
  toLabel="Shape"
  items={[
    { from: "Query Q",              to: "3 × 768"  },
    { from: "Key K",                to: "3 × 768"  },
    { from: "Key Transposed Kᵀ",    to: "768 × 3"  },
    { from: "Q × Kᵀ → Scores",     to: "3 × 3"    },
  ]}
/>

Why the transpose? We cannot multiply `(3×768) × (3×768)` — the inner dimensions don't match. Transposing the Key gives `(768×3)`, making the multiplication `(3×768) × (768×3) = (3×3)` ✓

The embedding dimension **disappears** after multiplication. The output is always `n × n` where n = number of tokens.

---

## Mathematics

<MathBlock title="Attention Score Computation">
  $$\text{Attention Scores} = QK^T$$
</MathBlock>

<MathBlock title="Dimension Example">
  $$(3 \times 768) \times (768 \times 3) = (3 \times 3)$$
</MathBlock>

The result is a square matrix where every Query has been compared against every Key simultaneously.

---

## Engineering Insight

The Attention Score Matrix is **not** a learnable parameter — it is a temporary tensor created during every forward pass.

## Key Takeaways

- GPT compares **Query** with **Key** to measure relevance between tokens.
- The Dot Product (matrix multiplication) is the similarity measure.
- The Key matrix is transposed before multiplication.
- The Attention Score Matrix has shape **n × n** (tokens × tokens).
- The embedding dimension disappears after the multiplication.
- Attention Scores are temporary — computed fresh for every sentence.
- These scores are raw similarities, not probabilities yet.

## What's Next?

We now have the **Attention Score Matrix**.

But there is one major problem — as the embedding dimension grows larger, the Dot Product values also grow larger. Large values make learning unstable.

So before converting these scores into probabilities, GPT performs one simple but critical operation: dividing every score by

$$\sqrt{d_k}$$

In the next lesson, we'll discover **why this tiny mathematical operation is essential for stable Transformer training**.
