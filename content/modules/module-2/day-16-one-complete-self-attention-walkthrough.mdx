## The Complete Formula

<MathBlock title="Scaled Dot-Product Self-Attention">
  $$\text{Attention}(Q, K, V) = \text{Softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
</MathBlock>

Every step from Days 11–15 lives inside this single equation.

---

## Key Takeaways

- Every token creates Query, Key and Value vectors.
- Query compares with every Key to compute Attention Scores.
- Scaling by √dₖ keeps the scores numerically stable.
- Softmax converts the scores into a probability distribution.
- Attention Weights determine how much information to gather from each token.
- Value vectors provide the actual information.
- The Context Matrix is the final output — each token now understands its sentence.
