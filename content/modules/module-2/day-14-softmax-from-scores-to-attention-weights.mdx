## How Softmax Works — Two Steps

### Step 1 — Apply the Exponential Function

<TokenMapping
  title="Step 1: Exponentiation"
  fromLabel="Scaled Score"
  toLabel="e^score"
  items={[
    { from: "3.46", to: "e³·⁴⁶ = 31.82" },
    { from: "2.96", to: "e²·⁹⁶ = 19.30" },
    { from: "2.67", to: "e²·⁶⁷ = 14.44" },
  ]}
/>

Exponentiation guarantees every value becomes **positive**.

### Step 2 — Normalize

Divide every exponential by the sum of all exponentials.

<TokenMapping
  title="Step 2: Normalization (sum = 65.56)"
  fromLabel="Exponential"
  toLabel="Probability"
  items={[
    { from: "31.82 / 65.56", to: "0.47" },
    { from: "19.30 / 65.56", to: "0.29" },
    { from: "14.44 / 65.56", to: "0.24" },
  ]}
/>

Result: `0.47 + 0.29 + 0.24 = 1.00` ✓

## Mathematics

<MathBlock title="Softmax Function">
  $$\text{Softmax}(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}$$
</MathBlock>

Applied to one row of the Attention Score Matrix, Softmax converts raw scores into a probability distribution that sums to 1.

---

## Complete Scaled Dot-Product Attention

<MathBlock title="Full Attention Formula">
  $$\text{Attention}(Q, K, V) = \text{Softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
</MathBlock>

This single equation captures the entire computation covered across Days 11–14:
1. `QKᵀ` — compare every Query with every Key
2. `÷ √dₖ` — scale for numerical stability
3. `Softmax(...)` — convert to probabilities
4. `× V` — use weights to compute a weighted average of Values

## Key Takeaways

- Raw Attention Scores cannot be used directly — they are not probabilities.
- Softmax applies exponentiation then normalization to each row.
- Every row becomes a valid probability distribution summing to 1.
- The result is the **Attention Weight Matrix**.
- These weights determine how much each token attends to every other token.
- The complete attention formula is `Softmax(QKᵀ / √dₖ) V`.

## Understanding the Tensor Shapes

Suppose the sentence contains 3 tokens. After scaling, GPT has the Scaled Attention Scores `(3 × 3)`.

Softmax is **not** applied to the entire matrix at once — it is applied **independently to each row**.

## Mathematics — Row by Row

<MathBlock title="Softmax Applied to One Row">
  $$\text{Softmax}(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}}$$
</MathBlock>

For one Query with scaled scores `[3.46, 2.96, 2.67]`:

<MathBlock title="Probability for Each Token">
  $$p_1 = \frac{e^{3.46}}{e^{3.46}+e^{2.96}+e^{2.67}} \approx 0.47 \qquad p_2 \approx 0.29 \qquad p_3 \approx 0.24$$
</MathBlock>

`0.47 + 0.29 + 0.24 = 1` — a valid probability distribution. ✓

## Common Misconceptions

**Softmax changes which token is most relevant.**

No. Softmax preserves the ranking — it only converts scores into probabilities.

**Softmax changes the tensor shape.**

No. Input `(n×n)` → Output `(n×n)`. Only the values change.

**The Attention Weight Matrix is trainable.**

No. It is a temporary tensor computed during every forward pass. Only WQ, WK, WV are trainable.
