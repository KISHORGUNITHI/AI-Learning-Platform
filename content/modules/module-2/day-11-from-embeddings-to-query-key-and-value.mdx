> *"One embedding cannot perform every responsibility. Before Self-Attention begins, GPT transforms it into three specialized representations."*

---

## Quick Recap

In the previous lesson we learned that every token creates three roles — Query, Key, and Value.

But one important question still remains:

> **Where do these three vectors actually come from?**

---

## The Problem

Suppose the token `Cat` has the embedding `[0.42, -0.81, 1.24, ...]`.

How does GPT suddenly obtain a Query, Key, and Value from this single vector?

Did engineers manually create them? Does GPT store three vectors per word?

No. GPT learns three different mathematical transformations during training.

---

## Intuition

Imagine a software engineer in a company. The same person can perform three completely different responsibilities:

- Asking questions during meetings
- Identifying the right experts
- Sharing their own knowledge

The person hasn't changed — only the role has changed.

Similarly, GPT starts with **one embedding vector**, then transforms it into three different representations, each with one specific responsibility.

---

## The Three Learnable Matrices

Instead of directly using the embedding during Self-Attention, GPT first creates Query, Key, and Value using three different learnable matrices:

## Understanding the Dimensions

Suppose the sentence has 5 tokens, each with a 768-dimensional embedding. The input matrix is `5 × 768`.

<TokenMapping
  title="Dimension Flow Through Each Transformation"
  fromLabel="Operation"
  toLabel="Result Dimensions"
  items={[
    { from: "Input Embeddings",     to: "5 × 768" },
    { from: "× WQ  (768 × 768)",    to: "5 × 768  → Query Matrix" },
    { from: "× WK  (768 × 768)",    to: "5 × 768  → Key Matrix"   },
    { from: "× WV  (768 × 768)",    to: "5 × 768  → Value Matrix" },
  ]}
/>

The sequence length (5) and embedding dimension (768) are **preserved** after every transformation. Only the internal representation changes.

---

## Mathematics

<MathBlock title="Query Matrix">
  $$Q = XW_Q \quad (5 \times 768) \times (768 \times 768) = (5 \times 768)$$
</MathBlock>

<MathBlock title="Key Matrix">
  $$K = XW_K \quad (5 \times 768) \times (768 \times 768) = (5 \times 768)$$
</MathBlock>

<MathBlock title="Value Matrix">
  $$V = XW_V \quad (5 \times 768) \times (768 \times 768) = (5 \times 768)$$
</MathBlock>

## Key Takeaways

- Every token starts with one embedding vector.
- GPT transforms that embedding into three different vectors using WQ, WK, WV.
- All three matrices are learnable parameters updated during training.
- Matrix multiplication creates Q, K and V while preserving tensor dimensions.
- Every token generates its own Query, Key and Value.
- Three separate matrices allow each representation to specialize.

## What's Next?

Every token now has its Query, Key, and Value vectors prepared.

But the model still doesn't know **which tokens are important**.

> **How does a Query decide which Keys are most relevant?**

GPT compares every Query with every Key using one of the simplest and most powerful operations in machine learning: **The Dot Product**.

That comparison produces the **Attention Scores** — which determine how much attention each token should pay to every other token.

In the next lesson, we'll build the intuition behind the Dot Product before introducing the complete Self-Attention computation.
