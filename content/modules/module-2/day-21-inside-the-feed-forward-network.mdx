## The Architecture

The Feed Forward Network is a small neural network — no Queries, no Keys, no Values. Just two linear layers with an activation in between.

## Every Token Uses the Same FFN

## Tokens Do NOT Communicate Inside the FFN

Inside Attention, tokens interact. Inside the FFN, that communication is finished — each token is processed independently.

## Engineering Perspective

The Transformer Block alternates between two jobs — communication then transformation — and repeats this pattern in every layer.

## Key Takeaways

- The FFN is two Linear layers separated by an Activation function.
- Every token passes through the **same** FFN.
- Tokens do **not** communicate inside the FFN.
- The FFN transforms each token independently after Attention.
- Every Transformer Block alternates: communicate → transform.
