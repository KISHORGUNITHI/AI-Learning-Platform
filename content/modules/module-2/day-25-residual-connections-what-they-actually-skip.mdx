## Then Why Is It Called a Skip Connection?

The **computation** is not skipped. Instead, the original input gets an **additional path** that runs alongside the computation.

## Why This Matters During Backpropagation

Without residual connections, the gradient has only one path through every layer.

<Comparison
  title="Without vs With Residual Connections"
  left={{

  right={{

    points: [

## The Mathematical Insight

Differentiate `y = x + F(x)` with respect to x:

<MathBlock title="Gradient Through a Residual Connection">
  $$\frac{dy}{dx} = 1 + \frac{dF(x)}{dx}$$
</MathBlock>

The **+1** is the key. Even if `dF(x)/dx ≈ 0` (the block learns nothing useful), the gradient remains `1 + 0 = 1` — strong enough to continue flowing backward.

<TokenMapping
  title="Why the +1 Changes Everything"

    { from: "With residuals, block learns well",      to: "1 + dF/dx > 1  — strong signal"  },

/>

## Key Takeaways

- "Skip Connection" is a misleading name — nothing is skipped.
- Every Transformer layer still performs its full computation.
- The original input travels **alongside** the computation via an identity path.
- During backpropagation, gradients flow as `1 + dF(x)/dx`.
- The `+1` ensures strong gradient flow even through very deep networks.
- Every Transformer block has **two** residual connections — one around Attention, one around FFN.
