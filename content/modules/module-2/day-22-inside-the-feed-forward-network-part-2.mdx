## Stage 2 — Feature Transformation (GELU)

The expanded representation passes through **GELU** — the dimensions stay at `3072`, but the values change.

## Mathematics

<MathBlock title="FFN Forward Pass">
  $$\text{FFN}(x) = W_2 \cdot \text{GELU}(W_1 x + b_1) + b_2$$
</MathBlock>

where **W₁** `(768 × 3072)` expands, **GELU** activates, and **W₂** `(3072 × 768)` compresses back.

---

## Engineering Insight

The FFN performs three jobs in sequence.

<FlowDiagram title="Three Jobs of the FFN" steps={[
  "Expand  →  Create more feature capacity (768 → 3072)",
  "Transform  →  Learn richer feature combinations (GELU)",
  "Compress  →  Return to original embedding dimension (3072 → 768)"
]} />

Each token undergoes this complete transformation **independently**.

---

## Key Takeaways

- The FFN transforms every token independently.
- The representation is temporarily expanded to 4× the embedding dim.
- GELU transforms feature importance without changing the shape.
- The representation is compressed back to the original embedding dimension.
- Output has the same shape as the input, but richer learned features.
