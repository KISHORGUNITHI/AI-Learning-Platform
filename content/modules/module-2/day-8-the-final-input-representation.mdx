## The Problem

Suppose the sentence is `I Love AI`.

GPT already has token embeddings (meaning) and positional embeddings (position).

Should it choose one? Ignore the other? Or combine both?

---

## Intuition

Imagine sending a package.

The package needs both the **item inside** and the **delivery address**. Having only one isn't enough.

Similarly, every token entering the Transformer needs **meaning** and **position** — together.

---

## Deep Explanation

Every token has two vectors — one from the **Token Embedding Matrix** and one from the **Positional Embedding Matrix**.

GPT combines them using one simple operation: **element-wise addition**.

<FlowDiagram title="Combining Token + Position" steps={[
  "Token Embedding  [T₀, T₁, T₂ ...]",
  "+ Positional Embedding  [P₀, P₁, P₂ ...]",
  "Element-wise Addition",
  "Final Input Representation  [T₀+P₀, T₁+P₁, T₂+P₂ ...]"
]} />

The result — the **Final Input Representation** — is what enters the first Transformer block.

> Addition preserves both meaning and position while keeping the embedding dimension unchanged.

---

Sentence: `The cat sleeps`

For the token `cat`:

The Transformer never processes raw text, Token IDs, or either embedding alone. It always processes the **combined representation**.

---

## Key Takeaways

- Every token has both meaning (token embedding) and position (positional embedding).
- GPT combines them using element-wise addition.
- The embedding dimension remains unchanged after addition.
- The resulting vector is called the Final Input Representation.
- This combined vector is the actual input to the first Transformer block.
