## The Problem

Suppose two vectors have 4 dimensions. Their Dot Product might be `3.5`.

Now imagine vectors with 768 dimensions. The Dot Product can be `42`, `67`, `95`, `128`.

As the embedding dimension grows, the Attention Scores naturally become much larger.

## Intuition — Why Size Makes Scores Explode

The Dot Product adds together hundreds of multiplications. For a large vector, hundreds of numbers are added — not because the vectors became "more similar", but simply because there are far more dimensions contributing to the sum.

## Mathematics

<MathBlock title="Scaled Attention Scores">
  $$\text{Scaled Scores} = \frac{QK^T}{\sqrt{d_k}}$$
</MathBlock>

where **Q** is the Query Matrix, **K** is the Key Matrix, and **dₖ** is the dimension of the Key vectors.

This scaling happens **before Softmax**.

---

## Why Large Dot Products Are Dangerous

Softmax uses the exponential function — and exponentials grow extremely fast.

<TokenMapping
  title="How Fast Exponentials Grow"
  fromLabel="Input"
  toLabel="eˣ output"
  items={[
    { from: "x = 2",  to: "≈ 7"           },
    { from: "x = 4",  to: "≈ 55"          },
    { from: "x = 8",  to: "≈ 2,981"       },
    { from: "x = 96", to: "≈ 10⁴¹  (!!)" },
  ]}
/>

When scores are `96`, `82`, `74`, the first exponential is astronomically larger than the rest — one token absorbs all the attention.

## What Is Softmax Saturation?

Without scaling, Softmax becomes extremely confident — almost all probability collapses onto a single token. This is **Softmax Saturation**.

<Comparison

  left={{

      "One token gets all the attention",
      "Other tokens are completely ignored",

## Why Saturation Breaks Training

During training, GPT learns through Backpropagation — which depends on gradients.

When Softmax saturates, its gradients become extremely small (**vanishing gradients**).

<FlowDiagram title="How Saturation Breaks Learning" steps={[
  "Large Attention Scores",
  "Softmax Saturates",
  "Probabilities near 0 or 1",
  "Gradients become near-zero",
  "Parameters barely update",
  "Learning stops effectively"
]} />

Scaling prevents Softmax from reaching this saturated state, allowing gradients to flow much more effectively.

---

## What Changes After Scaling?

Scaling does **not** change which token is most relevant — it only reduces the magnitude.

<TokenMapping
  title="Ranking is Preserved After Scaling"

The ordering is identical. Only the magnitude is reduced to a stable range.

---

## Key Takeaways

- Dot Products naturally grow as the embedding dimension increases.
- Softmax is highly sensitive to large input values because it uses exponentials.
- Large Attention Scores cause **Softmax Saturation**.
- Saturated Softmax produces probabilities close to 0 or 1, leading to vanishing gradients.
- Dividing by **√dₖ** keeps Attention Scores in a numerically stable range.
- Scaling **preserves the ranking** of scores — only the magnitude changes.

## What's Next?

We now have **Scaled Attention Scores** — raw numerical scores that are numerically stable.

The next step is to convert them into **probabilities** using the **Softmax Function**, creating the **Attention Weight Matrix**.

Each row of this matrix will represent a probability distribution — telling GPT exactly **how much attention each token should pay to every other token**.
