## The Problem

Suppose GPT decides Token A gets 47%, Token B 29%, Token C 24%.

Now what?

## Why Don't We Use Keys?

Keys were created only for **matching** — once GPT determines which tokens are relevant, Keys have completed their job.

## Mathematics

<MathBlock title="Final Self-Attention Step">
  $$\text{Context} = \text{Attention Weights} \times V$$
</MathBlock>

<MathBlock title="Dimension Example">
  $$(n \times n) \times (n \times d) = (n \times d)$$
</MathBlock>

<MathBlock title="Complete Self-Attention Formula">
  $$\text{Attention}(Q, K, V) = \text{Softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
</MathBlock>

## Engineering Insight — Why Matrix Multiplication is Efficient

GPT doesn't compute one weighted sum at a time — it computes **all of them simultaneously** using a single matrix multiplication.

## Worked Example

Attention Weights for `I Love AI`:

<TokenMapping
  title="Attention Weight Matrix"
  fromLabel="Query → [I, Love, AI]"
  toLabel="Weights"
  items={[
    { from: "I    (Query)", to: "[0.70, 0.20, 0.10]" },
    { from: "Love (Query)", to: "[0.15, 0.70, 0.15]" },
    { from: "AI   (Query)", to: "[0.10, 0.30, 0.60]" },
  ]}
/>

New representation for `Love`:

```text
0.15 × Value(I) + 0.70 × Value(Love) + 0.15 × Value(AI) = Context(Love)
```

`Context(Love)` is no longer just the embedding for "Love" — it contains 70% of "Love"'s knowledge plus context from "I" and "AI".

## Key Takeaways

- Attention Weights determine **how much** information to gather.
- Value vectors contain **what** information is gathered.
- GPT computes the Context Matrix using one single matrix multiplication.
- Output shape remains `(n × d)` — same sequence length and embedding dimension.
- Every output token now contains contextual information from the entire sentence.
- This Context Matrix is the output of the Self-Attention layer.
